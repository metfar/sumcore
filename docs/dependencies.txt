# SUM Ecosystem

## Install order

1. sumCore
2. sumFSA
3. sumIO
4. sumUI
5. sumData
6. sumPlot
7. sumGUI
8. sumTUI
9. sumR
10. sumPY
11. sumIDE
12. sumX
13. sumBASIC
14. sumbash
15. sumdiff
16. sumdoc
17. sumbuild
18. sumKeyboard

`sumFSA` owns logical/native filesystem translation, mounts, volumes and Locations.
`sumIO` owns capability-based files, standard streams, pipes, file descriptors and serial/COM resources.
The terminal/session layer remains above these two packages and is not part of this release.

## Optional audio backends

`sumCore` owns `sumaudiod`, `suminfo`, `sumbeep`, `sumsound`, and `sumplay`.
No additional Python dependency is required for the shared audio API.

Persistent `sumaudiod` output is selected from host commands when available:

1. PulseAudio `pacat` (preferred on Termux);
2. SoX `play`;
3. ALSA `aplay`.
