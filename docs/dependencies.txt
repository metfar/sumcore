## Optional audio backends

`sumCore` owns `sumaudiod`, `suminfo`, `sumbeep`, `sumsound`, and `sumplay`.
No additional Python dependency is required for the shared audio API.

Persistent `sumaudiod` output is selected from host commands when available:

1. PulseAudio `pacat` (preferred on Termux);
2. SoX `play`;
3. ALSA `aplay`.

On Termux, installing the `pulseaudio` package is recommended. `suminfo` reports
the detected sinks and the backend actually selected by the daemon.
